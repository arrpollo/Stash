# Bundled reading fonts

These fonts ship with Stash and are loaded locally. No font service or network connection is required.

- **Atkinson Hyperlegible**, regular and bold: unmodified files from the [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/atkinsonhyperlegible). Copyright 2020 Braille Institute of America, Inc. Licensed under the SIL Open Font License 1.1; see [Atkinson-OFL.txt](Atkinson-OFL.txt).
- **Lexend**, variable weight: unmodified file from the [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/lexend). Copyright 2018 The Lexend Project Authors, with Reserved Font Name “RevReading Lexend”. Licensed under the SIL Open Font License 1.1; see [Lexend-OFL.txt](Lexend-OFL.txt).

Files were retrieved September 12, 2026. System default, Verdana, Trebuchet, and Georgia use fonts available on the device, with CSS fallbacks.
